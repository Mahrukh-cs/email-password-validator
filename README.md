# Email & Password Validator

A client-side form validation tool that checks email format and password strength.

## Features

- ✅ Email format validation
- ✅ Password strength validation (8-20 chars, uppercase, lowercase, number, special char)
- ✅ Real-time error messages
- ✅ Success message display

## How to Use

1. Enter a valid email (e.g., user@example.com)
2. Enter a strong password (e.g., MyPassword123!)
3. Click Submit button
4. See success message if valid, error messages if invalid

## Password Requirements

- Minimum 8 characters
- Maximum 20 characters
- At least 1 uppercase letter (A-Z)
- At least 1 lowercase letter (a-z)
- At least 1 number (0-9)
- At least 1 special character (@$!%*?&)

## Valid Password Examples

✅ Secure@Pass9
✅ MyPassword123!
✅ Hello@World2024
